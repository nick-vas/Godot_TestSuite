# Changelog

## [1.1.0] - 2026-11-02

- The version is shown on the main menu.
- Release build of the eight levels and the daily drift.

## [1.0.0] - 2026-10-23

- Eight hand-made levels of sliding on ice, with snow, sparks and an exit that opens once every spark is collected.
- A daily drift: a level generated from the date, the same for every player.
- Undo, restart, and a line that says when the exit can no longer be reached.
- Menu, level select, pause, settings (volume, English, French, German), credits.
- Solved levels and their fewest moves saved; saves from version 0.x (a list of cleared levels) still load.
